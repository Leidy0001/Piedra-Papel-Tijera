# Piedra, papel o tijera

Un juego de piedra, papel o tijera contra la computadora, hecho con HTML, CSS y JavaScript.

## Demo

[Jugar en GitHub Pages](https://leidy0001.github.io/Piedra-Papel-Tijera/)

> **Publicación pendiente:** GitHub Pages aún no está activado para este repositorio. En **Settings → Pages**, selecciona **Deploy from a branch**, la rama **main** y la carpeta **/(root)**. Después de publicar, puedes copiar la URL de la demo al campo **Website** de **About**.

## Cómo jugar

Elige **Piedra**, **Papel** o **Tijera** con los botones, o usa las teclas **1**, **2** y **3**. Piedra vence a tijera, tijera vence a papel y papel vence a piedra. Si ambos eligen lo mismo, la ronda termina en empate.

La partida es al mejor de cinco: quien llegue primero a tres puntos gana. Usa **Reiniciar partida** para volver a empezar.

## Funciones

- Elección aleatoria de la computadora.
- Resultado de cada ronda y marcador actualizado.
- Partida al mejor de cinco con anuncio del ganador.
- Controles accesibles para teclado y botones cómodos en pantallas pequeñas.
- Reinicio de la partida en cualquier momento.

## Ejecutar localmente

Abre `index.html` en un navegador. No se necesitan dependencias ni un servidor.
